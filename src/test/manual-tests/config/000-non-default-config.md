# Manual Test: Non-default config

## Prerequisites

- None

## Steps

**Create configuration**

Create a configuration file (or docker compose file) that has non-default configuration and uses all available configuration options.

**Test deploy**

Deploy ffs with the configuration. Make sure that it starts correctly.

**Browse files**

Browse files via the file manager and check that everything in the test bench loads correctly. Including thumbnails, viewing images, and viewing videos.
